# Bản vá gộp trang chủ và menu

Gồm hai thay đổi tích lũy:
1. Ẩn khối Tin tức khỏi trang chủ; hiển thị 6 hoạt động theo mốc thời gian.
2. Đổi tên menu Tin tức thành Mở rộng, chuyển ngay sau Thi đua.

Chép các file trong `src/` vào đúng đường dẫn của dự án hiện tại. Không xóa các file khác. Kiểm tra diff trước khi commit và chạy build.

Không có SQL migration. Giữ nguyên các file Markdown cũ của dự án. Xem README riêng của từng bản vá để biết thêm chi tiết.
